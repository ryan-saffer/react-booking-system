The **Reports** page uses the studio selected at the top right of the Portal. It is available only to people whose role
includes reporting access.

<Aside type="note" title="Check the selected studio first">
  A report can be accurate and still answer the wrong question if a different studio or the master organisation is
  selected.
</Aside>

## Holiday Program Capacity

This report shows upcoming classes, booked children, total capacity, remaining spots, and utilisation. Confirm the
selected studio and the **Updated** time. Use **Refresh** for a new snapshot. Master access can switch between studio and
daily breakdowns.

## Party Capacity Utilisation

This report counts stored **in-studio** birthday party bookings in the date range and compares that count with the number
of available booking slots you enter.

<Steps>
  1. Choose the start and end dates. 2. Enter the total slots offered in that period. 3. Run the report. 4. Read the
  booked count and utilisation percentage together.
</Steps>

For a master report, the entered available slots are applied to each studio. Mobile parties are not included.

<Aside type="caution" title="Available slots are not calculated">
  The Party Capacity report trusts the number you enter. If opening hours, blocked dates, or the studio schedule
  changed, update that number before comparing periods.
</Aside>
