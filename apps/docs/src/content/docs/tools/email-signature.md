Use the Fizz Kidz Signature Creator, then add the generated signature to Gmail.

- [Open the Fizz Kidz Signature Creator](https://sites.google.com/fizzkidz.com.au/fizz-kidz-signature-creator?usp=sharing)

## How to use it

1. Enter your details in the signature creator.
2. Click **Select signature**.
3. Copy the signature with `Cmd + C` on Mac or `Ctrl + C` on Windows.
4. In Gmail, go to **Settings** > **See all settings**.
5. Scroll to **Signature**, create or select your signature, and paste it in.
6. Choose it as the default for new emails and replies if required, then save your changes.
7. Send yourself a test email and check the links, image, spacing, and mobile layout.
